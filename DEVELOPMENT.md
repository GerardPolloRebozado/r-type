# Development

## How to setup

Required dependencies:

- CMake 3.28
- vckpkg
- autoconf
- automake 
- libGL
- libGLU
- libX11 
- libXcursor
- libXinerama
- libXrandr
- libXi
- libXxf86vm
- wayland
- wayland-protocols
- libxkbcommon

1. First clone this repository:
```bash
git clone git@github.com:GerardPolloRebozado/zappy.git
```
2. Install dependencies with:
```bash
cd enginer && vcpkg install
```
