# Features

- **Entity Component System (ECS)**: A fully custom, highly optimized ECS core.
- **Plugin Architecture**: Easily extend the engine or editor via modular plugins.
- **Real-time Editor**: Integrated ImGui-based editor with Scene Serialization (JSON).
- **Audio Pipeline**: Seamless ECS-based audio integration with Raylib.
- **Networking**: Multi-player support out of the box.
