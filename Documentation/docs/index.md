# Lucky & Pozzo. A curious partnership in game-making.

This duo of Editor (Lucky) and Game Engine (Pozzo), is a modern Entity Component System (ECS) game engine tailored for 2D games. The engine built in C++23 with Raylib, and the addition of imGui for the visual editor, has allowed us to provide an architecture for handling game logic, rendering, networking, and audio.

Check out the [Getting Started Guide](./getting_started/tutorial.md). Basic programming logic is expected, but the scripting language that is used on the engine (Lua) is really easy to pick up. If you want to learn a bit of Lua, and have a go with a simpler framework, check out [How to LÖVE](https://www.sheepolution.com/learn/book/0), as it provides an introduction to the language, and to LÖVE, a tool to build games as well.
