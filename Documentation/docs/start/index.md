# Start

Welcome to our game development project. In this section, you will be introduced to the different concepts that are good to have heard about before starting a project.

This tool has two parts. _Lucky_, the visual editor, and _Pozzo_, the game engine. 

You can implement any game you want using Pozzo as a C++ library, and code in C++. However, for big projects, this may get uncomfortable, slow, or annoying. Having to set up every single scene with C++, place the entities manually, etc. is not really exciting. 

That is why we are lucky to have Lucky. It is a visual editor that allows you to create any game without writing a single C++ line. Placing the entities in a visual environment, and writing the game logic in Lua, seems a more exciting and simpler experience than having to do everything from scratch in C++, right?

In any case, here you have multiple guides to develop games using either of the tools.

- [Installation](installation.md)  -  Build the engine and editor on your machine.
- [Core concepts](concepts.md)  -  The vocabulary used across the engine, the editor, and multiplayer.
- [Your first game in the editor](first-game-editor.md)  -  Create a scene, place entities, and press play.
- [Your first game in C++](first-game-engine.md)  -  Link the engine, write your first systems, and run the application.
